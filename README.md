EXPENSE TRACKER — PERSONAL FINANCE TRACKER

OVERVIEW
Expense Tracker is a responsive personal finance tracker. It lets users record income and expenses, calculate their balance automatically, categorize transactions, search and filter history, delete records, and keep data in browser local storage.

FILES
- index.html: website structure
- style.css: layout, styling, pastel theme, and responsive rules
- script.js: transaction management, calculations, filtering, deletion, and local storage
- README.md: project information

RUN LOCALLY
1. Extract the project ZIP.
2. Open index.html in a browser, or use VS Code with Live Server.

PUBLISH WITH GITHUB PAGES
1. Upload index.html, style.css, script.js, and README.md to the root of your repository.
2. In Settings > Pages, select Deploy from a branch, choose main and /(root), then save.

STORAGE AND PRIVACY
Transactions are stored in localStorage in the current browser. They are not synchronized to other devices or backed up to a server. Clearing browser storage may delete them. This is a demo/personal tracking tool, not a bank-connected service.

SOURCE NOTE
The supplied code contains HTML, CSS, and JavaScript rather than Java source code. This project is packaged as a static front-end application and does not require a Java runtime.
